# Release ladder

- v0.1: delivered product shell; reproducible install, CI build/security checks, honest simulator and tested state transitions.
- v0.2: delivered one lesson → evidence → repair → verify → explanation → changed scenario flow with deterministic assessment tests.
- v0.3: delivered versioned local practice persistence with refresh/reset/retry semantics and explicit untrusted-state boundary. This is not authoritative mastery persistence; accounts remain deferred until cross-device/server-trusted state is justified.
- Quality gate: delivered production Chromium E2E in CI, including persistence hydration, reset/restart, corrupt/stale storage, unavailable Storage API, responsive overflow, keyboard focus and runtime-error checks.
- Breadth gate: next, broaden Linux/OS/network foundations and unfamiliar diagnosis before presenting the six curriculum cards as delivered A–Z coverage.
- v0.4: real Linux labs only after isolation, quotas, TTL, cleanup and escape tests pass.
- v0.5–v0.7: Docker, Kubernetes, CI/CD and IaC vertical slices with verifiers and cost budgets.
- v0.8–v0.9: observability/SRE and unfamiliar cross-domain incidents.
- v1.0: coherent zero-to-production curriculum with demonstrated transfer, accessibility and operational readiness.

No version is complete solely because its code exists. Consult PROJECT_STATE for actual verification/merge status.
