# Release ladder

- v0.1: executable product shell; reproducible install, CI build/security checks, honest simulator and tested state transitions. Requires successful CI and merge, not merely source files.
- v0.2: one lesson → evidence → repair → verify → explanation → changed scenario flow; deterministic assessment tests. Current primary frontier.
- v0.3: versioned progress/mastery persistence, refresh/retry tests, clearly defined trust boundary; add accounts only when cross-device state requires them.
- v0.4: real Linux labs only after isolation, quotas, TTL, cleanup and escape tests pass.
- v0.5–v0.7: Docker, Kubernetes, CI/CD and IaC vertical slices with verifiers and cost budgets.
- v0.8–v0.9: observability/SRE and unfamiliar cross-domain incidents.
- v1.0: coherent zero-to-production curriculum with demonstrated transfer, accessibility and operational readiness.

No version is complete solely because its code exists. Consult PROJECT_STATE for actual verification/merge status.
