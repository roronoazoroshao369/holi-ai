# HOLI DEVOPS

North star: diagnose, repair, verify and explain an unfamiliar operational incident.
Current delivery: v0.1 product shell with a SIMULATED Linux permission incident. Curriculum cards are a proposed syllabus, not delivered lessons.
Learning loop: understand → observe → hypothesize → experiment → diagnose → repair → verify → explain → transfer.
Do not count page visits or command replay as mastery. v1.0 requires coherent fundamentals, evidence assessments, persisted mastery, isolated execution where appropriate and cross-domain capstones.
