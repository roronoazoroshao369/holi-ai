# HOLI DEVOPS

North star: diagnose, repair, verify and explain an unfamiliar operational incident.
Current product phase: v0.3 learning slice. Delivered practice has six primary SIMULATED incidents: four Linux permission/TCP incidents and two Git/CI artifact/revision incidents, plus bounded permission/listener/path/tag transfers and versioned same-browser checkpoints. Git revision locks source-linked rationale before repair. Curriculum cards are a proposed syllabus, not delivered lessons.
Learning loop: understand → observe → hypothesize → experiment → diagnose → repair → verify → explain → transfer.
Local persisted completion is continuity evidence only, not trusted mastery. Do not count page visits, command replay or editable client state as certification. v1.0 requires coherent fundamentals, broader unfamiliar assessments, an authoritative mastery model where justified, isolated execution where appropriate and cross-domain capstones.
