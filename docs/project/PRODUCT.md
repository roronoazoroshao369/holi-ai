# HOLI DEVOPS

North star: diagnose, repair, verify and explain an unfamiliar operational incident.
Current product phase: v0.3 learning slice. Delivered practice has seven primary SIMULATED incidents: four Linux permission/TCP incidents and three Git/CI artifact/revision/graph incidents, plus bounded permission/listener/path/tag/linear-history transfers and versioned same-browser checkpoints. Git revision and graph practice lock source-linked rationale before repair. Graph transfer changes the integration policy from ordered direct parents to base ancestry plus a reviewed fixture change series. Curriculum cards are still mostly a proposed syllabus, but one Git foundations lesson is now delivered before graph practice.
Learning loop: understand → observe → hypothesize → experiment → diagnose → repair → verify → explain → transfer.
Local persisted completion is continuity evidence only, not trusted mastery. Do not count page visits, command replay or editable client state as certification. v1.0 requires coherent fundamentals, broader unfamiliar assessments, an authoritative mastery model where justified, isolated execution where appropriate and cross-domain capstones.




## Git foundations lesson — 2026-10-06

The delivered lesson teaches snapshot identity, moving refs, direct parents and ancestry with a fixture that is deliberately separate from the graph assessment corpus. Its readiness check is local teaching state only and cannot grant assessment credit. It hands the learner into the existing graph incident after the four mental-model checks. This improves preparation; it is not a new incident, trusted mastery signal or replacement for unfamiliar assessment.
